# Директория содержит конфигурационные файлы myRPC

## myRPC.conf
- `port` - порт для соединений (по умолчанию 8642)
- `socket_type` - тип сокета (реализован только stream)
- `mode` - режим работы (daemon или console)
- `log_file` - путь к файлу лога (пусто - использовать syslog)

## users.conf
Список пользователей, которым разрешен доступ к серверу.
Каждый пользователь указывается с новой строки.
